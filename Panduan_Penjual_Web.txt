=====================================================
 PANDUAN PENJUAL — APLIKASI TANDA TERIMA SERVICE (WEB)
=====================================================

APA INI
  Aplikasi Tanda Terima Service versi ONLINE (web).
  Bisa diakses dari komputer, HP, atau laptop mana pun
  — tanpa WAJIB instal software (cukup buka browser).
  Cocok untuk kasir bengkel/layanan servis perangkat.

ISI PAKET (service-receipt-casaos.zip)
  - install.sh        : skrip instal UNIVERSAL (semua server ber-Docker)
  - docker-compose.yml: konfigurasi service
  - Dockerfile        : definisi image (otomatis dibangun saat instal)
  - public/           : tampilan web
  - src/              : kode server
  - .env.example      : contoh pengaturan akun admin
  - render.yaml       : untuk deploy di platform Render
  - railway.json      : untuk deploy di platform Railway

FITUR
  - Tanda terima (input pelanggan, device, keluhan, biaya, DP)
  - Cetak: Struk DotMatrix, Setengah A4, A4  + Export PDF
  - Upload LOGO toko (tampil di semua cetakan & PDF)
  - Dashboard statistik + Laporan pendapatan per periode
  - Cari & filter status (Diterima/Diproses/Selesai/Diambil)
  - Halaman "Cek Status" untuk PELANGGAN (tanpa login)
  - Kirim link status langsung ke WhatsApp pelanggan (tombol 🔗)
  - Login admin + bisa ganti password

CARA JUAL
  Mode 1 — Paket install sendiri (sekali bayar):
    Kirim ZIP + panduan. Pembeli install sendiri di server
    ber-Docker (CasaOS / VPS / mini PC). Anda tidak ada
    biaya bulanan.

  Mode 2 — SaaS langganan (bulanan): SUDAH TERBUILT (multi-tenant)
    Satu server, banyak toko. Tiap toko daftar sendiri dan data
    mereka TERPISAH satu sama lain.
    - Toko daftar di:  /daftar   (masa trial 3 hari, bisa diubah)
    - Toko pakai:       /        (login dengan akun mereka)
    - Pelanggan cek:    /track.html?u=<username-toko>
    - Anda kelola:      /admin   (panel penjual)

  PANEL ADMIN ANDA (/admin, login admin)
    1. Lihat semua toko + status (Trial / Aktif / Habis / Nonaktif)
    2. Konfirmasi pembayaran 1 klik → toko otomatis aktif +30 hari
    3. Perpanjang manual / nonaktifkan / aktifkan toko
    4. Buat akun toko manual (tanpa menunggu daftar sendiri)
    5. Atur harga (Rp/bulan), lama trial, no. rekening tujuan transfer

  ALUR TRIAL & BILLING (otomatis)
    - Toko daftar → TRIAL 3 hari, fitur penuh.
    - Masa habis → otomatis terkunci (super admin akses data tetap).
    - Toko upload bukti transfer dari halaman bayar (muncul otomatis
      saat habis) → Anda konfirmasi di /admin → aktif 30 hari.
    - Kalau sudah aktif, banner di aplikasi menampilkan sisa hari.

SARAN HARGA (menyesuaikan pasar EXE Anda)
  - Mode paket  : sesuaikan dengan harga EXE (jual per instalasi)
  - Mode SaaS   : default sistem Rp 50.000/bulan per toko
                  (bisa diubah kapan saja di /admin)

BATASAN PAKET SAAT INI
  - Pembayaran = TRANSFER + KONFIRMASI manual oleh penjual.
    (Integrasi Midtrans/QRIS otomatis bisa ditambahkan kemudian,
    butuh akun merchant resmi).
  - Versi ini multi-tenant (banyak toko di 1 server).

CATATAN PENTING
  - Ganti password admin panel setelah install (via env
    ADMIN_USERNAME / ADMIN_PASSWORD, atau default admin/admin123
    — SEBAIKNYA ganti saat pertama deploy).
  - Backup berkala: salin folder data/ SELURUHNYA
    (master.db + tenants/ = data semua toko).
  - Akses yang sudah ada (versi lama satu-toko) otomatis diimpor
    menjadi toko pertama saat server pertama kali dijalankan
    dengan versi baru. Username/password tetap sama.
